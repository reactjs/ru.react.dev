2020 год был долгим. В конце года мы хотели поделиться специальным праздничным обновлением о наших исследованиях **React Server Components** с нулевым размером бандла.

</Intro>

---

Чтобы представить React Server Components, мы подготовили доклад и демо. Если хотите, можете посмотреть их во время праздников или позже, когда работа возобновится в новом году.

<YouTubeIframe src="https://www.youtube.com/embed/TQQPAU21ZUw" />

**React Server Components все еще находятся в стадии исследований и разработки.** Мы делимся этой работой в духе прозрачности и для получения первоначальной обратной связи от сообщества React. На это будет много времени, поэтому **не чувствуйте, что вам нужно наверстать упущенное прямо сейчас!**

Если вы хотите посмотреть их, мы рекомендуем делать это в следующем порядке:

1.  **Посмотрите доклад**, чтобы узнать о React Server Components и увидеть демо.

2.  **[Клонируйте демо](http://github.com/reactjs/server-components-demo)**, чтобы поиграть с React Server Components на своем компьютере.

3.  **[Прочтите RFC (с FAQ в конце)](https://github.com/reactjs/rfcs/pull/188)** для более глубокого технического разбора и предоставления обратной связи.

Мы будем рады услышать ваши отзывы в RFC или в ответах на аккаунт [@reactjs](https://twitter.com/reactjs) в Twitter. С праздниками, берегите себя и до встречи в следующем году!
