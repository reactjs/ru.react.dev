<Intro>

Документация React на [react.dev](https://react.dev) содержит документацию для последней версии React.

</Intro>

Мы стремимся обновлять документацию в рамках основных версий и не публикуем версии для каждого минорного или патч-релиза. Когда выходит новая основная версия, мы архивируем документацию для предыдущей версии как `x.react.dev`. Подробнее см. в нашей [политике версионирования](/community/versioning-policy).

Архив предыдущих основных версий вы можете найти ниже.

#### Устаревшая документация {/*legacy-docs*/}

В 2023 году мы [запустили новую документацию](/blog/2023/03/16/introducing-react-dev) для React 18 на [react.dev](https://react.dev). Устаревшая документация React 18 доступна на [legacy.reactjs.org](https://legacy.reactjs.org). Версии 17 и ниже размещены на устаревших сайтах.

Для версий старше React 15 см. [15.react.dev](https://15.react.dev).

</Note>
